# 氛围后期:模型做不到的那一半

## 为什么要单独有这一层

YuE2 **没有响度/力度参数**,输出又是**已经混好的单轨**。而"朦胧、迷离、轻抚、若隐若现、若即若离"
在真实制作里靠的是**自动化**(音量包络、干湿比、滤波扫频、声像游走)。

**这一层基本不在模型里,在后期。** 换多少标签都到不了。

值得注意的是:**dream pop 本来就是"把整体埋进空间"**,而不是把人声单独拿出来做 ——
所以"整轨处理"在这个风格里不是退而求其次,它接近这个风格本来的做法。

## 四项对应表

| 你要的 | 怎么做 | 实测效果 |
|---|---|---|
| **朦胧** | 高频滚降 + 短延迟 | 高频占比 0.46% → **0.08%** |
| **迷离** | 立体声加宽 + 相位 + 多级延迟 | 宽度 0.307 → **0.525** |
| **轻抚** | 去浑浊 + 中频靠近 + 轻柔压缩 | 3 kHz 占比 0.52% → **1.54%** |
| **若即若离** | 干湿分离,左右**不同延迟** | 锁相相关 0.062 → **0.479** |

**"锁相相关"** 是判断"远近是否真在变"的关键指标:它衡量立体声宽度是否**按你设定的周期**起伏。
不要用"宽度标准差"——源本身因编曲变化就在 0.70~0.17 之间波动,会把调制淹没。

## 两个必踩的坑

### ① 不能用 `loudnorm` 对齐响度

`loudnorm` 是**动态归一化**,会把音量包络压平(实测起伏 **7.49 → 4.99 dB**);
而且它内部**升采样到 192 kHz** —— 不锁采样率就会得到 4 倍长度的垃圾
(拼接时 48k 和 192k 混在一起)。

**正确做法:两遍处理。**

1. 第一遍:只跑滤镜链(不加响度),输出到临时文件
2. 用 `ebur128` 量出 LUFS
3. 第二遍:用**固定增益** `volume=<目标-实测>dB` 拉到 −16 LUFS

这样动态完全保留,而且各变体响度一致(否则 A/B 对比没有意义)。

### ② 湿信号左右必须用**不同**延迟

如果湿信号左右延迟相同,它和干声**一样宽**,调制只能改"回声量",改不了"距离"。

改成**左右不同延迟**后:湿 = 宽而散(**远**),干 = 实而窄(**近**),
此时调制湿的电平才真的在改距离。

## 参考滤镜串

⚠️ 输出参数 `-ar 48000 -ac 2` **必须写在 `-i` 之后**(写在前面会被当成输入选项,
报 `Option sample_rate not found`)。

```powershell
$FF = 'D:\mt-tool\ffmpeg\bin\ffmpeg.exe'

# 朦胧
$hazy = 'highpass=f=60,lowpass=f=5000,aecho=0.8:0.9:120|320:0.40|0.22'

# 迷离(slev 1.75 加宽 + 相位翻转 + 缓慢相位器 + 三级延迟)
$dreamy = 'stereotools=mlev=1.0:slev=1.75:phaser=1:phasel=1,aphaser=decay=0.35:speed=0.25,aecho=0.8:0.9:90|260|610:0.45|0.30|0.18'

# 轻抚
$caress = 'highpass=f=110,equalizer=f=3000:t=q:w=1:g=2,acompressor=threshold=-18dB:ratio=3:attack=20:release=400,aecho=0.8:0.9:70:0.25,stereotools=mlev=1.1:slev=1.15'
```

**若即若离**(复杂图,`-filter_complex`;周期 14 秒,干声反向让位):

```
asplit=2[d][w];
[d]volume=volume='1-0.45*(0.5+0.5*sin(2*PI*t/14))':eval=frame[dm];
[w]channelsplit=channel_layout=stereo[l][r];
[l]aecho=0.85:0.9:55|125|215|330|470|640|840:0.60|0.50|0.42|0.34|0.27|0.20|0.15[lw];
[r]aecho=0.85:0.9:75|160|260|395|560|760|980:0.60|0.50|0.42|0.34|0.27|0.20|0.15[rw];
[lw][rw]join=inputs=2:channel_layout=stereo[ws];
[ws]volume=volume='0.05+0.95*(0.5+0.5*sin(2*PI*t/14))':eval=frame[wm];
[dm][wm]amix=inputs=2:normalize=0
```

> 抽头越多越像混响。只有两三个抽头是"回声",不是"空间"。

## 现成实现

```powershell
& $PY $ROOT\scripts\dream-atmos.py --process   # 6 条链 + 对比带 + 试听页
& $PY $ROOT\scripts\dream-atmos.py --measure   # 客观指标表
```

脚本已内建:两遍固定增益对齐 −16 LUFS、采样率锁 48 kHz、`loudnorm` 那两条坑的规避。
输出在 `output\dream\` 与 `output\dream-compare.html`。

## 还差什么

- **人声单独进退**:当前的呼吸是**整轨**的。要做到"只有人声忽远忽近",需要**人声分离**
  —— audio.cpp 自带 `htdemucs`(`-Models` 加 `demucs`,权重 59–80 MB)与
  `bs_roformer`(164 MB),但**当前编译未含**,要重编译。
- **倒放混响尾巴**(`areverse`):dream pop 的招牌音色之一,这轮**没加**。

## 边界

- 这一层是**唯一能自动质检**的:锁相相关、宽度、频段占比都是客观数字。
  **生成层做不到自动质检** —— 所以"氛围类"目标尽量压到这一层来做。
- 但"够不够朦胧""好不好听"仍然**只能用户判断**。
