# 唱法与歌词:6 种演绎的实测状态

## 总表(全部实测,不要越过)

| 演绎方式 | 状态 | 怎么做 |
|---|---|---|
| **有词演唱** | ✅ 稳定 | 正常写歌词;ASR 曾把 251 个词逐字转对 |
| **`la la la` 音节** | ✅ 有效 | 音节直接当歌词写 |
| **忐忑式音节** | ✅ **唯一有客观正面信号的** | 密集非词音节(ASR 转出 222 个连续 "oh") |
| **第五元素式花腔** | ⚠️ 未判定 | 高音区 + `coloratura soprano` 类标签;ASR 对它完全无效 |
| **气声 / 喘息** | ❌ **没达标,只能算哼唱** | 见下;要真正的喘息得走语音模型混音 |
| **纯器乐** | ✅ 有效 | 保留段落标签 + **歌词行留空** |
| **人声退场** | ✅ 用 `[Instrumental]` | ⚠️ **段落留空做不到这件事** |
| **若隐若现 / 若即若离** | ⚠️ 只能整轨 | 人声单独进退需人声分离(未编译);见 `mixing.md` |

## 气声写法(能做到"哼唱",做不到"喘息")

**先说清楚物理限制**:YuE2 **没有响度/力度参数**,输出是归一化立体声 WAV,
所以命令不了它"唱小声"。"低声"只能往**音色**方向逼近。
真正的"喘息"是不可听的噪声(无基频),而这是学唱歌的模型 —— 它给的是**带气流的短元音**。

实测有效的写法(`scripts/breath-vocals.py`):

1. **一个音节一行** —— 换行是节拍线索,一行一个「哈」比一行十个更容易落在拍上
2. **用语气字而不是词**:啊 哈 嘿 呼 唉 嗯 嘶,配 `!` 与 `——`
3. **音色标签点名要气声**:`breathy vocal` `whispery vocal` `husky vocal`
   `intimate close-mic vocal` `ASMR whisper vocal`
4. **曲风选本来就大量用气声的**:`dark R&B` / `trap soul` / `ambient pop` / `city pop`
5. **节奏感靠编曲标签**:`minimal punchy beat` `syncopated groove` `808 bass` `four-on-the-floor`

**实测对照**(同歌词同 seed,只有人声标签不同):

| | 高频能量占比 | 过零率 |
|---|---|---|
| 气声版 | **0.0436** | **0.0601** |
| 去掉气声标签 | 0.0212 | 0.0396 |

气声版高频约 2 倍、过零率更高 —— 说明**标签确实在起作用**,但**听感上仍只是哼唱**。
⚠️ 编曲差异也会拉高这两个数,这只是参考,**听感判断必须用户做**。

**如果重复音节被"唱散"**:调 `semantic_repetition_penalty`(默认 **1.2** 会主动压制字面重复,
而这类 hook 靠的就是字面重复),可降到 **1.0–1.05**。

## 歌词规范

### 段落标记(必须是这些英文词)

`[Intro]` `[Verse]` `[Chorus]` `[Bridge]` `[Outro]` `[Instrumental]`

### 硬性要求

- **歌词不能为空** —— 服务会拒(`lyrics 不能为空`);全空白也拒。
- 纯器乐做法:保留段落标签 + **歌词行留空**(见下例)。
- 时长由歌词长度决定,目标秒数换算见主文件(1 秒 = 25 语义 token)。

### 纯器乐模板

```
[Intro]



[Verse]



[Chorus]



[Outro]

```

### 人声进出的正确做法

⚠️ **段落留空不会让人声退场**。实测:一个"交替留空"的谱子,人声从 **0:00 一直唱到 0:41**,
留空的段落被唱成了**无词长音(啊)**而不是器乐。

要人声真的退场,用 `[Instrumental]`:

```
[Intro]



[Verse]
夜色很轻 落在我肩上
[Instrumental]



[Verse]
再靠近一点 别说破
[Outro]

```

实测这样做出 **0:00–0:30 是器乐**(转出 whisper 的经典幻觉短语,器乐段的标志),
0:30 之后才开口。

> **注意**:即使这样,也**只做到"一次进出"**。人声坐在哪主要由模型自己决定,
> 歌词结构只能弱影响编排。要"反复进出"必须走分轨(未编译)。

## 歌词写作要点

- **每段别塞太多**:上游建议单段约 30 秒的歌词量。音节重复比堆词更稳。
- **语言标签决定唱什么语言**,歌词本身也要用对应语言写。
- 想要"若隐若现"的**结构感**,可用 `[Instrumental]` 分段制造间奏;
  想要**空间感**(飘远、朦胧),那在后期层做(见 `mixing.md`),不在歌词层。

## 不做的事

- ❌ 不要用 ASR 判断"有没有人声" —— 对无词吟唱它会把纯元音硬塞成幻觉短语。
- ❌ 不要用乐谱判断"有没有在唱" —— 实测器乐方案的乐谱里人声部照样有旋律线。
- ❌ 不要声称听过成品 —— 本 harness 无音频输入。
