## 三条最容易被忽略的事实

1. **本 harness 听不到音频** —— DSH 的输入模态只有 text 与 image。
   氛围判断("够不够朦胧""像不像人声")只能由人听。
2. **YuE2 不接受参考音频或人声参考** —— 源码显式拒绝,能力声明为 false,实测被静默忽略。
   分析参考曲得到的是**特征 → 标签**,不是"复刻"。
3. **风格标签的影响是概率性的** —— 同一提示词两次结果不同。想要某种效果请出多版让人挑。

## 术语

| 词 | 意思 |
|---|---|
| **ABC** | 模型输出的记谱格式(`V: Vocal` / `A2A2B2d2`),给机器读的;界面换算成**简谱**给人看 |
| **cot** | 规划路线。`off` 不写谱最快;`melody` 只规划旋律;`full` 旋律 + 和弦 |
| **语义 token** | 模型内部的时间单位。**25 个 = 1 秒**(实测精确) |
| **RTF** | 生成耗时 ÷ 音频时长。越小越快;出歌 0.49–0.74,转谱 0.053–0.19 |
